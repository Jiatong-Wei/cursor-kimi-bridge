### 1. 诊断链：有没有第三解释

**判定：有，而且其中一条已经跑过。** 「approach 不收敛 + 欠深 4.5cm」把两件不同的事焊在一起，还用错了尺子。

- **尺子错了。** 「纯策略从未 &lt;8cm」在 **n50** 上成立（3D min_ee）。同一 36k、n10：ep0 的 **xy_min=4mm**、ep3 xy_min=1.4cm。3D min_ee 0.106 是高度差，不是 xy 没对准。C-v1c 才是真的 xy 散（五集 xy_min 全 &gt;10cm）——那是这条配方，不是「策略从来不会对准」。
- **n50 chunk 惯性：已有判别，结果被丢掉了。** 工单①后 n10 vs n50 同 ckpt：median 0.106 vs 0.160，n50 0/5 &lt;8cm。方案 C 整弧却把评估改成 n50。hybrid 基线 0.042 是 **n10**；C-v1/C-v1c hybrid 是 **n50**。用 0.042 当「协同消失」的对照，协议不同构。
- **action_clip 0.01 不是主因。** n50/n10/hybrid 的 `|pred_dxyz|≥0.01` 只占 5–21% 帧，trans_norm_mean≈0.006，平均没有顶满裁剪。它能解释偶发削峰，解释不了「从未对准」。
- **OBS-41 欠深：几何成立，归因过满。** hybrid ep3：d&lt;5cm 共 55 帧，ee_z 0.059–0.070（中位 0.066），cube_z≈0.019。但 v7 写的目标是 `cube_z+0.094≈0.113`，同段 `ik_target.z` 却停在 **0.060**。加大 z-step 0.008→0.02 之前，先解释这条覆写为什么没写进 IK；按代码符号，加大步长是把 TCP **往 0.114 抬**，不一定更深。

### 2. W19 0-for-2 是否过早

**判定：过早。median「parity」是真噪声；「协同消失 vs 0.042」被协议污染；W19 无增益可以当工作假说，不能当结案。**

- 0.142 vs 0.160：配对 2 集更好、2 集灾难（0.351/0.383）、mean **0.223 vs 0.155**。n=5 Wilcoxon 到不了 0.05。说 parity 是又一次用 median 抹掉失败集。
- hybrid 0.206 vs 0.042：对照是 n10 vs n50。C-v1c **自己的** hybrid（0.233）比自己的纯策略（0.142）更差——这不是「制导没激活」（没激活应≈纯策略），是 hybrid 在这条上净负或方差爆炸。
- 替代解释（比「丢 xy → 制导不激活」更硬）：C-v1 脏数据 hybrid 仍 3/5 &lt;8cm（median 0.074，同为 n50）。更脏的纯策略反而让 hybrid 摸到近区。C-v1c 更干净、hybrid 更差，和「需要对准才能激活」交叉。n=5 也够把这种交叉当成噪声。

0-for-2 只能写成：*这两次混入 W19 都没有把 n50 纯策略变成稳定 &lt;8cm。* 不要写成「W19 oracle 修正演示无效」。

### 3. R4P 先验与 sunk cost

**判定：可见闭环改善的先验低（我标 ~20–30%，不是精确概率）；R4P 已在跑就让它跑完；parity 之后立刻 C-v2 是 sunk-cost 漂移。**

### 4. batch_size 不变量

**判定：不够立论。** 想隔离的实验是 C-v1b（脏数据 + 更新对齐），训练 40 分钟被杀掉了。现存对比是：
