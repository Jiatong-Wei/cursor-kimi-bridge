### 1. 诊断链：有没有第三解释

**判定：有，而且其中一条已经跑过。** 「approach 不收敛 + 欠深 4.5cm」把两件不同的事焊在一起，还用错了尺子。

- **尺子错了。** 「纯策略从未 &lt;8cm」在 **n50** 上成立（3D min_ee）。同一 36k、n10：ep0 的 **xy_min=4mm**、ep3 xy_min=1.4cm。3D min_ee 0.106 是高度差，不是 xy 没对准。C-v1c 才是真的 xy 散（五集 xy_min 全 &gt;10cm）——那是这条配方，不是「策略从来不会对准」。
- **n50 chunk 惯性：已有判别，结果被丢掉了。** 工单①后 n10 vs n50 同 ckpt：median 0.106 vs 0.160，n50 0/5 &lt;8cm。方案 C 整弧却把评估改成 n50。hybrid 基线 0.042 是 **n10**；C-v1/C-v1c hybrid 是 **n50**。用 0.042 当「协同消失」的对照，协议不同构。
- **action_clip 0.01 不是主因。** n50/n10/hybrid 的 `|pred_dxyz|≥0.01` 只占 5–21% 帧，trans_norm_mean≈0.006，平均没有顶满裁剪。它能解释偶发削峰，解释不了「从未对准」。
- **OBS-41 欠深：几何成立，归因过满。** hybrid ep3：d&lt;5cm 共 55 帧，ee_z 0.059–0.070（中位 0.066），cube_z≈0.019。但 v7 写的目标是 `cube_z+0.094≈0.113`，同段 `ik_target.z` 却停在 **0.060**。加大 z-step 0.008→0.02 之前，先解释这条覆写为什么没写进 IK；按代码符号，加大步长是把 TCP **往 0.114 抬**，不一定更深。

**30 分钟判别（R4P 让出 GPU 后再跑，现在不要开）：** 同一 `smolvla-planc1c` checkpoint，只改 server `--n_action_steps 10`，纯策略 5 集。若 n10 出现 xy&lt;8cm 而 n50 没有，approach 诊断就是执行层产物。36k 上这个实验已经做过。第二刀（仍 30 分钟）：36k hybrid 保持 n10，只把 v7 的 `+0.094` 改成实测指垫高度再评 5 集——测的是几何常数，不是「步长」。

### 2. W19 0-for-2 是否过早

**判定：过早。median「parity」是真噪声；「协同消失 vs 0.042」被协议污染；W19 无增益可以当工作假说，不能当结案。**

- 0.142 vs 0.160：配对 2 集更好、2 集灾难（0.351/0.383）、mean **0.223 vs 0.155**。n=5 Wilcoxon 到不了 0.05。说 parity 是又一次用 median 抹掉失败集。
- hybrid 0.206 vs 0.042：对照是 n10 vs n50。C-v1c **自己的** hybrid（0.233）比自己的纯策略（0.142）更差——这不是「制导没激活」（没激活应≈纯策略），是 hybrid 在这条上净负或方差爆炸。
- 替代解释（比「丢 xy → 制导不激活」更硬）：C-v1 脏数据 hybrid 仍 3/5 &lt;8cm（median 0.074，同为 n50）。更脏的纯策略反而让 hybrid 摸到近区。C-v1c 更干净、hybrid 更差，和「需要对准才能激活」交叉。n=5 也够把这种交叉当成噪声。

0-for-2 只能写成：*这两次混入 W19 都没有把 n50 纯策略变成稳定 &lt;8cm。* 不要写成「W19 oracle 修正演示无效」。

### 3. R4P 先验与 sunk cost

**判定：可见闭环改善的先验低（我标 ~20–30%，不是精确概率）；R4P 已在跑就让它跑完；parity 之后立刻 C-v2 是 sunk-cost 漂移。**

1582/28961=5.5% 是恢复后的占比。抽签存活约 15% → 原先大约 200 余帧。6–7× 修正帧在 BC 里经常被 94% 的 descend/接近轨迹淹没，尤其特权状态已经泄漏 cube xyz。OBS-39 作为**过滤器互食案例**成立；作为「DAgger 四轮失败的主因」是未检验的连带。

R4P 平了 → C-v2 低空采集：仍在「再喂修正演示」轨道上，已经 0-for-2。那不是证伪后的下一假说，是同一假说换高度。该 fallback 的合法条件只有：n10 重评仍对准失败，**并且** hybrid 几何常数已修过仍欠深。现在两条都没做。

### 4. batch_size 不变量

**判定：不够立论。** 想隔离的实验是 C-v1b（脏数据 + 更新对齐），训练 40 分钟被杀掉了。现存对比是：

| | 数据 | bs × 步数 | 调度器 |
|---|---|---|---|
| C-v1 | 脏 46465 | 8×13k（样本对齐） | warmup 400 / decay 11k |
| C-v1c | 干净 41642 | 4×36k（更新对齐） | 大概率未同比缩放 |

数据清洁度、更新次数、调度器、帧数同时变。只能说「脏+短训更差，干净+长训回到噪声带」，不能说「更新次数是正确不变量」。save_freq / epoch 边界同样没排除。要立论，至少补一刀：干净数据 + bs8×13k（现在这个 30–40 分钟量级才有判别价值，脏数据上的 v1b 没有）。

### 5. 为什么不用 RL

**判定：三条里 (b) 清醒，(a)(c) 半清醒半挡箭牌。约束下有中间路，但今晚不该开。**

- (a) 「8GB 跑不动 RL 样本量」对 **从零 on-policy PPO/SAC 在 Isaac 里采样** 基本成立。对 **offline**（IQL/CQL/IWR）和 **reward-ranked BC** 不成立——数据已经在磁盘上。
- (b) 若 Report #2 的研究对象是 VLA/BC 管线，上 RL 会换题。这是目标约束，不是借口。
- (c) reward hacking 真实，但 0/5 抓取时连稀疏成功奖励都还没试过，这句话现在主要用来停止搜索。

最小可行（均在 R4P 释放 GPU 之后，且都小于再采 2 小时）：

1. **Reward-ranked BC / 过滤式重训**（最小）：用现有 trace 按 min_ee 或「xy&lt;8cm 且 grip 开」加权/丢弃，同一 36k 配方重训一短截。测的是「演示质量」不是新奖励。
2. **IQL on DAgger 离线**（中）：r1–r4 已经是 (s,a,s') + 教师动作，不需要新环境交互。8GB 只跑 critic+actor。成功标准预注册：n10、5 集、median 相对 36k 左移，不看 grasped。
3. **残差 RL 只在最后 5cm**（更大，排后）：hybrid 已经能进 5cm 的回合上，对 Δz/grip 做短 horizon。现在 hybrid 协议还没冻，不该上。

不要用「上 RL」替代把 n10 和 TCP 几何做对。

### 6. 系统性盲区（2–3 条，带反向验证）
